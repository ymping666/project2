Understanding this scale

E Minor pentatonic uses the scale degrees 1, b3, 4, 5, b7, measured from E. The fretboard marks every matching pitch class from open strings through fret 12. The piano highlights the ascending register used in playback; other octaves contain the same pitch classes.

Minor pentatonic uses five degrees: 1, b3, 4, 5, b7. It omits degrees 2 and b6 from natural minor.

Standard guitar tuning: string 6 → 1, E2 · A2 · D3 · G3 · B3 · E4.
