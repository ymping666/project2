Understanding this scale

F Harmonic minor uses the scale degrees 1, 2, b3, 4, 5, b6, 7, measured from F. The fretboard marks every matching pitch class from open strings through fret 12. The piano highlights the ascending register used in playback; other octaves contain the same pitch classes.

Harmonic minor uses 1, 2, b3, 4, 5, b6, 7. Raising natural minor’s seventh creates a three-semitone gap from b6 to 7.

Standard guitar tuning: string 6 → 1, E2 · A2 · D3 · G3 · B3 · E4.
