Understanding this scale

F# Major pentatonic uses the scale degrees 1, 2, 3, 5, 6, measured from F#. The fretboard marks every matching pitch class from open strings through fret 12. The piano highlights the ascending register used in playback; other octaves contain the same pitch classes.

Major pentatonic uses five degrees: 1, 2, 3, 5, 6. It omits degrees 4 and 7 from major.
