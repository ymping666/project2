Understanding this chord

C Minor seventh uses the scale degrees 1, b3, 5, b7, measured from C. A voicing arranges those notes in a particular register. An inversion names which chord tone is lowest; it does not change the chord’s pitch classes.

A minor seventh chord adds a minor seventh to a minor triad: 1, b3, 5, b7.
