Understanding this chord

E Suspended fourth uses the scale degrees 1, 4, 5, measured from E. A voicing arranges those notes in a particular register. An inversion names which chord tone is lowest; it does not change the chord’s pitch classes.

A suspended fourth chord uses a perfect fourth instead of a third: 1, 4, 5. With no third, this formula is neither a major nor a minor triad.
