Understanding this chord

F Suspended second uses the scale degrees 1, 2, 5, measured from F. A voicing arranges those notes in a particular register. An inversion names which chord tone is lowest; it does not change the chord’s pitch classes.

A suspended second chord uses a major second instead of a third: 1, 2, 5. With no third, this formula is neither a major nor a minor triad.
