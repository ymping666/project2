Understanding this chord

Eb Diminished uses the scale degrees 1, b3, b5, measured from Eb. A voicing arranges those notes in a particular register. An inversion names which chord tone is lowest; it does not change the chord’s pitch classes.

A diminished triad has a minor third and a diminished fifth: 1, b3, b5. Its semitone formula is 0–3–6.
