Understanding this chord

F# Dominant seventh uses the scale degrees 1, 3, 5, b7, measured from F#. A voicing arranges those notes in a particular register. An inversion names which chord tone is lowest; it does not change the chord’s pitch classes.

A dominant seventh chord adds a minor seventh to a major triad: 1, 3, 5, b7. The seventh is ten semitones above the root.
