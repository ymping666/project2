Understanding this scale

E Melodic minor (ascending) uses the scale degrees 1, 2, b3, 4, 5, 6, 7, measured from E. The fretboard marks every matching pitch class from open strings through fret 12. The piano highlights the ascending register used in playback; other octaves contain the same pitch classes.

This study uses ascending melodic minor: 1, 2, b3, 4, 5, 6, 7. Natural minor’s sixth and seventh are raised. Traditional descending melodic minor returns to natural minor; that descending form is not played here.

Piano notes use scientific pitch notation; C4 is middle C. Each key is one semitone from its neighbor.
