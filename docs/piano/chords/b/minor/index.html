Understanding this chord

B Minor uses the scale degrees 1, b3, 5, measured from B. A voicing arranges those notes in a particular register. An inversion names which chord tone is lowest; it does not change the chord’s pitch classes.

Piano notes use scientific pitch notation; C4 is middle C. Each key is one semitone from its neighbor.
